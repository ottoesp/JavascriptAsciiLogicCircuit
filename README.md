## JS ASCII Logic Circuit Generator

This is a tool I created in high school as an assignment in my IB diploma. There is some jankyness throughout and I was still getting used to using git so please excuse some of the rough edges. 
However there are some cool algorithms throughout and it was a great learning exercise for me.

I have recently revamped this project into [this repo](https://github.com/ottoesp/logicgatediagramgenerator) which improves on sections I was unhappy with.
